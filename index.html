Diamond command referenceเพชร คู่มือคำสั่ง

Every command shipped by the Diamond plugin, what it does, and what it expects. All commands hang off the /d root. ทุกคำสั่งของปลั๊กอิน Diamond พร้อมคำอธิบายว่าทำอะไรและรับอาร์กิวเมนต์อะไรบ้าง คำสั่งทั้งหมดอยู่ภายใต้ /d

Commandsคำสั่ง

Three groups: the diamond economy, the countdown that runs on it, and the prank/utility tools. <> = required, [] = optional (opens a dialog instead). แบ่งเป็น 3 กลุ่ม: เศรษฐกิจเพชร, การนับถอยหลังที่ขับเคลื่อนโดยมัน, และเครื่องมือแกล้ง/อำนวยความสะดวก <> = จำเป็น, [] = ไม่บังคับ (จะเปิดกล่องโต้ตอบแทน)

Diamond economyระบบเพชร

/d diamond add <amount>

Adds diamonds to the shared counter. If the count reaches max, the countdown starts automatically. เพิ่มเพชรลงในตัวนับรวม หากจำนวนถึงค่าสูงสุด การนับถอยหลังจะเริ่มโดยอัตโนมัติ

amountrequired — integer > 0จำเป็น — จำนวนเต็ม > 0
Plays a ding when it executes.มีเสียงดิ๊งเมื่อรันคำสั่ง
/d diamond remove <amount>

Subtracts diamonds from the counter, clamped at 0. Stops an active countdown. ลดจำนวนเพชรในตัวนับ (ไม่ต่ำกว่า 0) และหยุดการนับถอยหลังที่กำลังทำงานอยู่

amountrequired — integer > 0จำเป็น — จำนวนเต็ม > 0
Plays a ding when it executes.มีเสียงดิ๊งเมื่อรันคำสั่ง
/d diamond reset

Zeroes the counter and stops any running countdown. Shows a red reset on the player's screen. รีเซ็ตตัวนับเป็น 0 และหยุดการนับถอยหลังทั้งหมด แสดงตัวอักษรสีแดง reset บนหน้าจอผู้เล่น

No confirmation — runs immediately.ไม่มีการยืนยัน — ทำงานทันที
/d diamond setmax <n>

Sets the target diamond count. Run without a number to edit it in a dialog. กำหนดจำนวนเพชรเป้าหมาย พิมพ์โดยไม่ใส่ตัวเลขเพื่อแก้ไขผ่านกล่องโต้ตอบ

noptional — dialog opens if omittedไม่บังคับ — จะเปิดกล่องโต้ตอบถ้าไม่ใส่
Persisted to plugins/Diamond/ds_store.yml.บันทึกลงใน plugins/Diamond/ds_store.yml.

Countdown & configนับถอยหลังและการตั้งค่า

/d countdown start

Starts the countdown from the configured duration. Safe to call repeatedly — a running countdown is left alone. เริ่มการนับถอยหลังจากระยะเวลาที่ตั้งไว้ เรียกซ้ำได้ปลอดภัย — ถ้ากำลังนับถอยหลังอยู่แล้วจะไม่ถูกยุ่ง

/d countdown stop

Stops the countdown and clears its state. หยุดการนับถอยหลังและล้างสถานะ

/d countdown set <seconds>

Sets the countdown duration. Run without a number to edit it in a dialog. กำหนดระยะเวลานับถอยหลัง พิมพ์โดยไม่ใส่ตัวเลขเพื่อแก้ไขผ่านกล่องโต้ตอบ

secondsoptional — dialog opens if omittedไม่บังคับ — จะเปิดกล่องโต้ตอบถ้าไม่ใส่
Persisted to ds_store.yml.บันทึกลงใน ds_store.yml.
/d config

Opens a single dialog to edit both max diamond and countdown duration at once. เปิดกล่องโต้ตอบเดียวเพื่อแก้ไขทั้ง เพชรสูงสุด และ ระยะเวลานับถอยหลัง ในครั้งเดียว

applyinternal — apply <max> <seconds>ภายใน — apply <max> <seconds>
apply maxedit only max — apply max <n>แก้เฉพาะเพชรสูงสุด — apply max <n>
apply countdownedit only seconds — apply countdown <n>แก้เฉพาะวินาที — apply countdown <n>

Pranks & toolsแกล้งและเครื่องมือ

/d prank cobweb <seconds>

Encases the player's feet and head in cobweb, then restores the blocks after the timer. กักผู้เล่นด้วยใยแมงมุมที่เท้าและหัว จากนั้นคืนสภาพบล็อกเมื่อเวลาหมด

secondsrequired — duration to stay trappedจำเป็น — ระยะเวลาที่ติดอยู่
/d prank tnt <amount>

Spawns fused TNT on the player: knockback yes, block destruction no. Grants 10s of damage immunity. วางทีเอ็นทีติดฟิวส์บนตัวผู้เล่น: มีแรงเหวี่ยง ไม่ทำลายบล็อก และกันความเสียหาย 10 วินาที

amountrequired — number of TNT entitiesจำเป็น — จำนวนทีเอ็นที
/d mobspawn <mob> <amount>

Spawns mobs at the player's position. Tab-completes registered spawnable entities. วางม็อบที่ตำแหน่งผู้เล่น แท็บได้รายชื่อม็อบที่วางได้ทั้งหมด

mobrequired — e.g. creeper, zombieจำเป็น — เช่น creeper, zombie
amountrequired — how many to spawnจำเป็น — จำนวนที่ต้องการ
/d helpdiamond <seconds>

Turns every solid block in a radius of 20 into deepslate diamond ore, then restores them after the timer. แปลงบล็อกทึบทุกก้อนในรัศมี 20 ให้เป็นเพชรแร่ดีปสเลต จากนั้นคืนสภาพเมื่อเวลาหมด

secondsrequired — how long the ore lastsจำเป็น — ระยะเวลาที่แร่อยู่
Bedrock and existing diamond ore are left untouched.บล็อกเบดร็อกและเพชรแร่เดิมจะไม่ถูกแตะ

Playerผู้เล่น

/d getkits

Gives the player the starting kit. แจกชุดเริ่มต้นให้ผู้เล่น

/d hud

Toggles the on-screen diamond HUD for the player. เปิด/ปิด HUD แสดงเพชรบนหน้าจอ

/d nightvision

Toggles the night vision effect. เปิด/ปิดเอฟเฟกต์การมองเห็นตอนกลางคืน

/d regen

Toggles the regeneration effect. เปิด/ปิดเอฟเฟกต์ฟื้นฟูพลังชีวิต

Config GUIตั้งค่า GUI

Right-click the diamond item (custom model data 1) in hand to open the 54-slot configuration screen. It lives alongside the commands — same settings, different surface. คลิกขวาที่ไอเทมรูปฟันเฟือง ในมือเพื่อเปิดหน้าตั้งค่า ใช้ชุดการตั้งค่าเดียวกับคำสั่ง — ข้อมูลชุดเดียวกัน หน้าตาต่างกัน

Togglesปุ่มเปิด/ปิด

HUD, regen, and night vision flip instantly when clicked. The item's model data reflects state (2 = on, 3 = off). HUD, การฟื้นฟู, และการมองเห็นกลางคืน สลับทันทีที่คลิก model data ของไอเทมสะท้อนสถานะ (2 = เปิด, 3 = ปิด)

Edit slotsช่องแก้ไข

The แก้ไขเพชรสูงสุด and แก้ไขเวลานับถอยหลัง items open a textbox dialog prefilled with the current value. The GUI reopens refreshed on confirm. ไอเทม แก้ไขเพชรสูงสุด และ แก้ไขเวลานับถอยหลัง จะเปิดกล่องโต้ตอบพิมพ์ข้อความพร้อมค่าปัจจุบัน แล้ว GUI จะเปิดใหม่พร้อมค่าล่าสุดเมื่อยืนยัน

Protected itemไอเทมป้องกัน

The GUI diamonds (CMD 1–3) can't be dropped, dragged, moved, or swapped between hands. เพชรใน GUI (CMD 1–3) ไม่สามารถทิ้ง ลาก ย้าย หรือสลับมือได้

Web Overlayโอเวอร์เลย์

A read-only progress bar of the diamond counter, served by the plugin itself. No config, no auth — it just works. แถบความคืบหน้าของตัวนับเพชรแบบอ่านอย่างเดียว เสิร์ฟโดยปลั๊กอินเอง ไม่ต้องตั้งค่า ไม่มีรหัสผ่าน — เปิดปุ๊บใช้ได้เลย
